# Turnos Campbell

## Cambios de interfaz

Se unificaron las vistas de **Paramédicos** y **Ambulancias** para que compartan una estructura visual consistente:

- Grilla de tarjetas compartida, con cuatro columnas en escritorio y diseño responsive en móvil.
- Barra de búsqueda con el mismo estilo y espaciado.
- Controles de filtro y orden alineados en ambas vistas.
- Selectores para ordenar por nombre o código.
- Colores, bordes, botones, estados y espaciado coherentes con la paleta existente.
- Se conservaron las APIs y la lógica actual de datos.

Archivos modificados:

- `public/index.html`
- `public/css/styles.css`
- `public/js/app.js`
